# Task Manager

## Features
- Enhanced task management application
- 10 categories
- Priority ranking
- File uploads
- Task details view
- Downloadable task details
- Search functionality

## Categories
1. Work
2. Personal
3. Shopping
4. Health
5. Education
6. Travel
7. Projects
8. Hobbies
9. Events
10. Miscellaneous

## How to Use
1. Create a task by selecting a category.
2. Rank the task by priority (High, Medium, Low).
3. Upload any related files.
4. View detailed information about the task.
5. Download task details for offline use.
6. Use the search function to find tasks quickly.
